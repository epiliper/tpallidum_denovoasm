# tpallidum_denovoasm

## Introduction
Syphilis is surging worldwide, with more than 8 million incident cases per year and causing more than 220,000 fetal and infant deaths from congenital syphilis, underscoring the urgent need to develop a vaccine. Recently, hybrid capture whole genome sequencing (WGS) of the causative organism, Treponema pallidum subspecies pallidum, has enabled cataloging of antigen sequences directly from clinical samples. 

Treponema pallidum is a fastidious Gram negative spirochete with a single 1.14 Mb syntenic chromosome. It has no known plasmids, phage, transposons or other mobile genetic elements. T. pallidum includes subspecies pallidum (TPA), pertenue (TPE), and endemicum (TEN), which are morphologically indistinguishable and cause venereal syphilis, yaws, and endemicum, respectively. With 99.8% pairwise identity between the subspecies, genomics approaches are broadly applicable across T. pallidum. 

This de novo assembly pipeline uses as input reads that have been filtered to remove human reads and contaminating rRNA and tRNA loci from other bacteria using Kraken2 followed by adapter and quality trimming with trimmomatic, as created during https://github.com/greninger-lab/tpallidum-variant-calling/tree/main or similar pre-processing methods. Reads are mapped to a reference containing 8 T. pallidum reference strains including SS14, Nichols, and MexicoA (TPA); Gauthier, SamoaD, and Fribourg-Blanc (TPE); and BosniaA and IraqB (TEN), followed by de novo assembly using megahit. The best-matching reference is selected based on kmer similarity and the contigs aligned to it, then gaps between contigs filled with reference. Iterative mapping of reads back to the hybrid consensus is used to generate a final sequence. Finally, ORFs are extracted from the consensus sequence.  

Although this approach generates highly accurate consensus sequences, known limitations include reference bias in subfamily 1 and 2 tpr genes, and artificial indels in repetitive sequences in TP0136, TP0424, and TP0769. Caution should be used when interpreting differences in these genes. Repetitive sequences in TP0433 (the acidic repeat protein) and TP0470 have been masked as they cannot be assembled from short reads.   

## Instructions

This pipeline is meant to be run on outputs generated by https://github.com/greninger-lab/tpallidum-variant-calling/, namely the output tRNA, rRNA, and genomic NA files. These are generally labeled with \*_tRNA\*,  \*_rRNA\*, and \*_tp_filtered\*, respectively.

This means each sample input to the pipeline must have three inputs (single- or paired-end). You can use the bin/python3_fastq_dir_to_samplesheet.py script to create an input samplesheet. For example: 

```bash
python3 bin/fastq_dir_to_samplesheet.py \
	s3://aws_dir_1 \
	s3://aws_dir_2 \
	/my/local/dir/ \
	--tprefix _tRNA --rprefix _rRNA --gprefix _tp_filtered
```

This will recursively search three directories to find all files with the patterns associated with their NA type and group them by their names *up to* the pattern. For example:

```
SAMPLE_1_tRNA.fastq.gz
SAMPLE_1_rRNA.fastq.gz
SAMPLE_1_tp_filtered.fastq.gz
-----------------------------
sample: SAMPLE_1

NEG_tRNA.fastq.gz
NEG_rRNA.fastq.gz
NEG_tp_filtered.fastq.gz
------------------------
sample: NEG
```

## Options

To see all options:

if running locally:
```bash
nextflow run /path/to/tpallidum_denovoasm/main.nf --help
```

if running off a git commit (example: latest):
```bash
nextflow run epiliper/tpallidum_denovoasm -r main -latest --help
```

samples with one or more missing NA files will be excluded from the samplesheet.
